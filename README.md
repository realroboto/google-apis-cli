# google-apis-cli (`gapi`)

CLI única para administrar Google Ads + GTM + GA4 (Admin+Data) + Search Console
sob **um login**, **read+write com todos os scopes**. Zero deps de terceiros —
só `google-auth-library` (Google-nativo) + `fetch` nativo → REST.

Substitui os 4 MCPs Google fragmentados do vmCODE. Spec via `/to-spec`.
